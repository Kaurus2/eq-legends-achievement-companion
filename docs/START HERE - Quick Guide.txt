EQ LEGENDS ACHIEVEMENT COMPANION — QUICK GUIDE
Updated September 14, 2026

1. Extract the ZIP to a folder and run EQ Legends Achievement Companion.exe.
2. Open the gear. Choose your EverQuest Legends game folder and click Find characters.
3. Select your character at the top. Export connected and Combat log connected confirm the files were found.
   If the export is missing, export your achievements in game. If the log is missing, use /log on.
   Scan again after creating the files. Advanced file settings contains manual path overrides.
4. Enable live updates to watch new combat log entries. Popups and sounds can be enabled separately.
   Live progress is an estimate. Refresh your achievement export periodically for accurate counters.
5. Click a tile to see locations and research. Click it again to deselect and shrink the panel.
   Farming research is shared; character progress and personal notes are separate.
6. Use Filters to narrow the list, or Table for a copyable grid.
7. The lightbulb switches light/dark mode. Pin keeps the app above other windows.
8. Drag Opacity to preview 15–100% transparency. The percentage changes as you drag.
   Release to save. The app returns to full visibility while focused and uses the saved level when you switch away.
9. Drag unused header space to move the window. Resize its edges. Your position and size are remembered.
10. Sound / popup options includes Test completion to preview the original victory fanfare.

UPGRADING
Close the app, replace only the executable in your existing folder, then reopen it.
Keep your existing data folder: it contains settings, character profiles, research, and notes.
To update: click the version status in the bottom-left corner, then Start update. Update checks run at startup and every six hours. Installation only begins when you choose Start update. The app downloads and verifies the executable, closes, replaces it, and reopens. Your data stays in place; the previous executable is saved as .previous. This is an achievement companion, with no DPS meter.

The illustrated PDF documents an earlier layout; use this quick guide for the current controls.

PET KILLS AND SEARCH
Pet kills are estimated after the log records your pet's "Attacking ... Master." response.
Issue a pet attack command after starting the Companion. A new pet response replaces the old name.
Other players' finishing blows are excluded. Keep chat/log filters enabled for pet responses.
Search checks achievement requirements and all candidate mobs, not just the selected farming option.
Refreshes keep recent ordering; only achievements gaining progress are promoted when Recent progress first is on.
BOTTOM-LEFT UPDATE STATUS
The footer shows the installed version and time since the last check.
Click it to check again; the information button opens patch notes for the installed version.
A gold Start update button appears when a newer version is available.
If checking fails, the footer offers Retry. Downloads and installation always need your click.

COMPACT LAYOUT
The Focus progress line stays visible. Expand Achievement summary for the detailed text and grouped bars.
Zone optimized Results is above the search field. Search includes achievement requirements and candidate mobs.
Recent progress first is inside Settings. Settings opens to its content height and can push achievements below view.
The muted opacity slider is in the title bar when space permits, and moves below it in compact windows.
